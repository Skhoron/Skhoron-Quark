# Contributing to Skhoron-Quark

Спасибо за интерес к проекту. Это исследовательский/учебный шифр —
контрибьюции, особенно критические (найденные слабости, атаки,
некорректные утверждения в `DESIGN_RATIONALE.md`), приветствуются
больше, чем где-либо ещё.

## Прежде чем предлагать изменения

1. Прочитайте [`docs/DESIGN_RATIONALE.md`](docs/DESIGN_RATIONALE.md) —
   там объяснено, почему сделано так, а не иначе, и какие вопросы
   уже помечены как открытые.
2. Прочитайте [`docs/DISCLAIMER.md`](docs/DISCLAIMER.md) — проект
   принципиально не претендует на production-готовность.

## Что особенно ценно

- **Найденные атаки или слабости** — даже частичные (например, снижение
  сложности атаки на N раундов из ROUNDS) — открывайте issue с деталями.
- **Формальный дифференциальный/линейный анализ** — если у вас есть опыт
  с SAT/MILP-инструментами, `analysis/differential_search.py` сейчас
  только заготовка, реальная реализация была бы огромным вкладом.
- **Constant-time аудит** — проверка скомпилированного кода через
  `dudect`/`ctgrind`, не только чтение исходников.

## Процесс

1. Форкните репозиторий, создайте ветку от `main`.
2. Убедитесь, что `cargo test --workspace` и `cargo clippy --workspace`
   проходят локально.
3. Откройте Pull Request с описанием, что и почему изменено.
4. Если меняете криптографические константы (ротации, число раундов,
   структуру key schedule) — обязательно обновите
   `docs/DESIGN_RATIONALE.md` с обоснованием.
